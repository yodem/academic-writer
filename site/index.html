From a rough idea to a footnoted article you can defend.

Academic Writer is a plugin for Claude Code that helps Humanities researchers write cited articles, in Hebrew or English. You get a Word file back, and you comment on it like any draft.

/plugin marketplace add yodem/academic-writer
/plugin install academic-writer@yodem

Run these two lines inside Claude Code, then restart it. Claude Code is Anthropic's AI assistant that runs in a terminal window; the install section explains the first steps.

1

Why not just ask a chatbot?

What a chatbot does

  • Invents plausible citations: real-sounding authors, page numbers nobody can find.
  • Flattens your voice into the same smooth prose it gives everyone.
  • Hands you a wall of text, with nothing you can comment on or trace.

What Academic Writer does

  • Checks every footnote against a page in the sources you chose.
  • Writes in your voice, learned from your own past articles.
  • Hands you a Word file that you edit like any draft.

The honest trade-off: drafting is slower than a chatbot, because the auditor blocks any claim it cannot match to a page. And it is not a ghostwriter. The thesis, the sources and the outline are yours.

Every footnote has to survive the auditor.

The auditor is the one mandatory gate in the whole flow. It is a separate checker, not the writer marking its own homework. It compares each footnote with the source page you chose. If it cannot confirm the citation, the paragraph does not pass.

ParagraphA drafted paragraph
Claim and footnote“…not only about authority.”1
Source pageScholem, p. 244
Quote matchedThe paragraph stays
Not foundRejected

Rejected paragraphs are rewritten with the auditor's feedback and checked again. If one keeps failing, it is named for you instead of being papered over.

What you get

It writes the way you write

Give it five to ten of your past articles. It learns your sentence length, the phrases you favour, and how you open and close an argument, then drafts in that voice. Run /academic-writer:init once to teach it; /academic-writer:voice manages what it has learned.

Hebrew is not an afterthought

Right-to-left layout and Hebrew footnotes come out right in the Word file. You choose the language at the start of every article, and the whole conversation follows.

Your library, read page by page

Upload an article (/academic-writer:ingest) or a whole book (/academic-writer:ingest-book) and keep its printed page numbers, so a footnote points to the page in your hand. Scanned pages and photos become text with /academic-writer:ocr.

/academic-writer:research returns only passages whose quotations were verified word for word. The optional Trove library is an online bookshelf for your sources, searched page by page.

Comment in Word, like on any draft

The draft arrives as a .docx with real footnotes and a bibliography. Add comments or tracked changes in Word. /academic-writer:revise groups them, asks you to confirm each group, and makes a new Word file. Repeat as often as you like.

Before you submit

/academic-writer:proofread

A marked-up copy and a short report. It never touches your original.

/academic-writer:review

A scorecard on six dimensions:

  • Structure
  • Argument logic
  • Citation completeness
  • Source coverage
  • Writing quality
  • Academic conventions

Install in three steps

  1. 1

    Install

    /plugin marketplace add yodem/academic-writer
/plugin install academic-writer@yodem

    Type or paste these inside Claude Code. Then restart Claude Code.

  2. 2

    Run setup (about 10 minutes)

    /academic-writer:setup

    It asks one question at a time: your field, your citation style, and a free Gemini key (click by click). It checks the helper tools and asks before installing anything, then writes a sample paragraph. Optional: /academic-writer:init learns your style from past articles.

  3. 3

    Write

    /academic-writer:write

    Claude guides you from topic to Word file, one decision at a time.

New to the terminal?
  • Mac Press Cmd and Space, type Terminal, press Enter.
  • Windows Open the Start menu, type PowerShell, press Enter.
  • Linux Open your Terminal app (often Ctrl+Alt+T).

Type cd, a space, then drag your research folder from Finder or Explorer into the window, and press Enter. Now you are working inside that folder.

Type claude and press Enter. If Claude Code is not installed yet, Anthropic's instructions walk you through it.

Privacy and your files

Who gets what

Anthropic
Your conversation, and the text Claude reads.
Google Gemini
Drafted paragraphs and source passages. On the free tier Google may use data to improve its products, so consider a paid key for sensitive unpublished work.
Trove
Only the sources you upload to it (optional).
Your computer
Keys live in the operating system's keychain and are never printed or written into the project.

Questions, answered plainly

Do I need to know programming?

No. You type in plain language, and the plugin asks one question at a time. The only technical step is pasting two lines to install it, and the install section shows how to open a terminal.

Does it make up citations?

It is built so that it cannot get away with it. Every footnote is checked against the sources you chose, and a separate checker rejects any paragraph whose citation it cannot confirm. Persistent failures are named for you.

Does it work in Hebrew?

Yes. Hebrew and English are both first-class, including right-to-left layout and Hebrew footnotes in the Word file.

Is it free?

The plugin is free and open source (MIT). It runs inside Claude Code, which needs a Claude plan, and it uses a Gemini API key, which has a free tier.

What if something breaks?

Run /academic-writer:health. It checks the setup and explains, in plain words, what is missing.

How do I update?

Run claude plugin marketplace update yodem and then claude plugin update academic-writer@yodem. Your data is kept.
