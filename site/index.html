Every footnote has to survive the auditor.

The auditor is the one mandatory gate in the whole flow. It is a separate checker, not the writer marking its own homework. It compares each footnote with the source page you chose. If it cannot confirm the citation, the paragraph does not pass.

Rejected paragraphs are rewritten with the auditor's feedback and checked again. If one keeps failing, it is named for you instead of being papered over.

/academic-writer:revise

Comment in Word. It folds your review back in.

Comment or track-change the draft like any paper, then let it fold your review back in, after you confirm each group.

  1. Comment in WordAdd comments or tracked changes to the .docx, save, and run revise.
  2. It sorts every commentInto four kinds, each with a proposed action.
  3. You confirm each groupOne group at a time. Nothing is applied unconfirmed.
  4. A new Word fileThen a short summary. Repeat as often as you like.

Your courses, kept in order.

For students and teaching researchers: set up a term once, and turn lecture recordings into structured lesson notes.

/academic-writer:courses

Courses

Give it your schedule once. Each course gets its own Drive folder, NotebookLM notebook and Trove notebook, and course materials are collected into them.

  1. Give it your schedule (.docx).
  2. It shows a table of courses, lecturers, days, hours and the folders it will create, with unclear entries flagged. You confirm before anything is created.
  3. It creates the course resources and asks before renaming or replacing anything.
  4. A check confirms every resource and reports mismatches. It never silently repairs or deletes.
  5. A daily scan collects new Moodle files, announcements and lesson recordings, and writes a short digest.

  • Recordings outside a course slot come to you for review. It never guesses.

/academic-writer:lesson-notes

Lesson notes

Give it a lecture recording and get one concise, structured Hebrew lesson note in that course's notebook. A note, not a transcript.

  1. Give it the audio, or let the daily scan queue it.
  2. It matches the recording time to your weekly schedule, and asks if it is unclear.
  3. NotebookLM transcribes it.
  4. It writes one Hebrew page and files it in the course's Trove book.

What you get

Your library, read page by page

Upload an article (/academic-writer:ingest) or a whole book (/academic-writer:ingest-book) and keep its printed page numbers, so a footnote points to the page in your hand. Scanned pages and photos become text with /academic-writer:ocr.

/academic-writer:research returns only passages whose quotations were verified word for word. The optional Trove library is an online bookshelf for your sources, searched page by page.

Hebrew is not an afterthought

Right-to-left layout and Hebrew footnotes come out right in the Word file. You choose the language at the start of every article, and the whole conversation follows.

Install

Cowork

Recommended

In the Claude desktop app for Mac or Windows. No terminal needed.

  1. Open the Claude desktop app and choose Cowork.
  2. In the left sidebar, click Customize, then Plugins.
  3. Click Add marketplace and enter: 
    yodem/academic-writer
  4. Pick academic-writer and click Install.

Then type this in Cowork:

/academic-writer:setup

Afterwards, run /academic-writer:health to check the helper tools. Cowork works in a folder you connect, and “Check for updates” brings newer versions.

Claude Code

If you already work in the terminal.

/plugin marketplace add yodem/academic-writer
/plugin install academic-writer@yodem

Type or paste these inside Claude Code. Then restart Claude Code.

Plugins you install in Cowork sync to your account, and to Claude Code.

Questions, answered plainly

Do I need to know programming?

No. You type in plain language, and the plugin asks one question at a time. In Cowork you install it with a few clicks; in Claude Code you paste two lines.

Does it work in Cowork?

Yes, and Cowork is the easiest way to start. Install it from Customize, then Plugins in the Claude desktop app for Mac or Windows. Cowork needs a paid Claude plan and works in a folder you connect.

Does it make up citations?

It is built so that it cannot get away with it. Every footnote is checked against the sources you chose, and a separate checker rejects any paragraph whose citation it cannot confirm. Persistent failures are named for you.

Can it learn my writing style?

Yes. It learns from three or more of your published articles. You choose the example paragraphs and edit the rules it drafts, and nothing is saved to your voice profile without your OK.

Does it work in Hebrew?

Yes. Hebrew and English are both first-class, including right-to-left layout and Hebrew footnotes in the Word file.

Is it free?

The plugin is free and open source (MIT). It runs inside Cowork or Claude Code, which need a paid Claude plan, and it uses a Gemini API key, which has a free tier.

What if something breaks?

Run /academic-writer:health. It checks the setup and explains, in plain words, what is missing.

How do I update?

In Cowork, use “Check for updates” in Customize, then Plugins. In Claude Code, run claude plugin marketplace update yodem and then claude plugin update academic-writer@yodem. Your data is kept.
