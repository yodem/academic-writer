How it works

The whole flow in fifteen seconds: set up, write with agents, revise.

An illustrated animation of the flow, in order:

  1. Run init once: your profile, voice, Trove, NotebookLM and Gemini are checked and ready.
  2. Run write: separate agents start in parallel. Evidence gathers verified quotes, Thesis offers three options, Architect plans five sections.
  3. Five writers draft the sections in your voice, and five auditors check every citation. A rejected citation goes back to its writer.
  4. Everything converges into article.docx, with footnotes, ready for Word.
  5. Run revise: your Word comments flow back to the writers and a new article-v2.docx is saved.

Install

Cowork

Claude desktop app · Mac or Windows

  1. Open Cowork, then Customize → Plugins.
  2. Add marketplace, then enter: 
    yodem/academic-writer
  3. Pick academic-writer and click Install. Then quit and reopen the app so the new commands appear.

Claude Code

In the terminal

  1. Paste these two lines, one at a time, pressing Enter after each: 
    /plugin marketplace add yodem/academic-writer
/plugin install academic-writer@yodem
  2. Quit Claude Code completely (type /exit) and open it again in the same folder.
New to Claude Code? Step by step, about 15 minutes
  1. You need a Claude plan that includes Claude Code (Pro, Max, Team or Enterprise; the free plan does not). Sign in or subscribe at claude.ai.
  2. Open the Terminal app (a window where you type commands): press Cmd+Space, type Terminal, press Enter. On Windows, use PowerShell from the Start menu.
  3. Paste this line and press Enter. It shows no progress for a minute; that is normal. (Windows PowerShell: irm https://claude.ai/install.ps1 | iex.) 
    curl -fsSL https://claude.ai/install.sh | bash
  4. Make a folder for your research (for example Academic inside Documents). In Terminal type cd (with a space), drag that folder into the window, press Enter, then type claude and press Enter.
  5. The first time, your web browser opens so you can sign in. Sign in, then return to the Terminal window.
  6. At the box where you type to Claude, paste the two install lines above, one at a time, pressing Enter after each. Each one prints a short confirmation. If the first says it cannot find the marketplace, check the line and try again; if it still fails, copy the message to Claude.
  7. Restart: type /exit and press Enter, then type claude again in the same folder.
  8. Type /academic-writer:setup and follow the questions. Setup asks before installing anything and explains each step.

If something fails: command not found: claude means you should close Terminal and open a new window. Type /plugin to check that academic-writer is listed under Installed. Otherwise, report a problem and paste what the screen says.

Then, in either one: 
/academic-writer:setup
→ 
/academic-writer:write

Questions, answered plainly

Do I need to know programming?

No. You type in plain language, and it asks one question at a time.

Does it make up citations?

Every footnote is checked against your sources; a separate auditor rejects any it can't confirm.

Does it work in Hebrew?

Yes: right-to-left layout and Hebrew footnotes in Word.

What happens to my files and data?
  • Anthropic sees your conversation and what Claude reads.
  • Gemini sees drafts and passages; free-tier data may improve Google products.
  • Trove (optional) holds only sources you upload.
  • Keys stay in your keychain; files are written only in your folder.
Is it free?

The plugin is free (MIT). Cowork and Claude Code need a paid Claude plan; Gemini has a free tier.

What if something breaks?

Run /academic-writer:health for a plain-words list of what is missing.

How do I update?

Cowork: “Check for updates” in Customize, then Plugins. Claude Code: claude plugin marketplace update yodem, then claude plugin update academic-writer@yodem.
