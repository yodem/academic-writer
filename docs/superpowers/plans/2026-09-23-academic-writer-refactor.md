# academic-writer refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This plan is executed under `/work` + ALE: each task's `ale-label` block (added by `ale plan bake`) is authoritative for lane, paths and acceptance.

**Goal:** Cut /write and /proofread cost by an order of magnitude while making the prose argue the author's thesis in the author's voice. The prose is grounded in verified evidence, a docx feedback loop improves both the voice and the plugin, and plugin construction follows Claude Code best practice.

**Architecture:**
- A TypeScript CLI `aw`, shipped in the plugin's `bin/`, runs every model call and deterministic step. It is invoked through Bash, not MCP (MCP has a hard ~60 s timeout), writes its artifacts to disk, and logs every call to a run ledger.
- Gemini flash does extraction, drafting and finding. An optional OpenRouter HTTP judge gives cross-family verification. Claude subagents remain only for the citation auditor (the hard gate) and the architect dialogue.
- Voice is one store in `${CLAUDE_PLUGIN_DATA}/voice/`, shared by every project.
- Dynamic workflows and the Gemini MCP server are removed.

**Tech Stack:** TypeScript (Node ≥20, esbuild, `node --test`), `@google/genai`, `fetch` for OpenRouter, Python 3 scripts (pytest), python-docx + lxml, hspell, `ck` CLI, Sefaria HTTP API, `claude plugin eval`.

**Spec:** `docs/superpowers/specs/2026-09-23-academic-writer-refactor-design.md` (rev 2, approved 2026-09-23). Evidence: `.ale/runs/aw-refactor-2026-09-23/evidence-*.md`.

## Global Constraints

- Numbers are never inlined. Every cap, budget, model id and concurrency lives in `src/thresholds.json` (new keys `models`, `budget`).
- Gemini runs on flash only, the latest id. Model ids appear only in `src/thresholds.json > models`.
- **Where the plugin writes.** Plugin runtime writes only inside the project (`CLAUDE_PROJECT_DIR`) and `${CLAUDE_PLUGIN_DATA}`. Nothing else under `$HOME`.
- **API keys.** Keys come only from userConfig `sensitive` values or the environment. The plaintext `.academic-helper/secrets.json` path is removed.
- **Hook guard.** Every hook silently skips a project without `.academic-helper/profile.md`.
- **Strict TypeScript.** No `any`. `npm run typecheck` passes for hooks and the CLI.
- **Failures are named.** A step that exceeds its budget exits `CAP_REACHED` or `ERROR`. A missing verdict is `ERROR`, never `PASS`. Model errors never fall back silently to another model.
- **Frontmatter.** Skills use documented frontmatter keys only: `name`, `description` (with "Use when…"), `allowed-tools`, `user-invocable`, `disable-model-invocation`, `model`, `effort`, `context`, `metadata`. Agents use `name`, `description`, `tools`, `disallowedTools`, `model`, `omitClaudeMd`.
- **Size.** Every SKILL.md is ≤ 500 lines.
- **Tests.** The existing suite stays green: `python3 -m pytest -q tests` (519 passing at the 2026-09-23 baseline, after rebasing onto `3d46c9b`).
- **Release.** Every slice ends with a release: version bump through `scripts/version-sync.py`, `npm run build`, marketplace refresh, and `claude plugin update`.
- **ALE and Codex stay out of the plugin.** The shipped plugin never calls the `ale` CLI or Codex.
- **Pi is isolated.** Pi is called only through `judge()` (Task 6), always with the isolation flags. The plugin stores no OpenRouter key; Pi's own auth owns it.
- **Jev runs only through `decide()`.** Every Jev use goes through `decide()` (Task 6) with a per-point mode in `thresholds.json > jev.points`. Hebrew points start in `shadow`, and moving a point to `cascade` is a release decision (at least 100 labels and the roster bar). Jev never skips the Claude citation auditor.

## Review Focus

1. **Two geresh abbreviations on one line with a typo between them** (`ר׳ יוחנן … להתפשר אם … עמ׳ 45`): the typo must be fixed and not treated as a quotation. Pinned in Task 7.
2. **The same `before` text occurring twice in a chunk:** anchoring picks the occurrence nearest the reported line. A true tie is reported as `ambiguous-anchor` and not applied. Pinned in Task 7.
3. **A Gemini reply cut off at the token limit** (`finishReason: MAX_TOKENS`): `aw` exits `ERROR` with the step id. It never parses partial JSON and never falls back. Pinned in Task 5.
4. **A new machine or project with no voice store:** `aw draft` refuses with exit code 3 and a message naming `aw voice pull`. It never drafts voiceless. Pinned in Task 10.
5. **A docx whose tracked change deletes a whole paragraph or is a move:** `aw docx read` still reports it, as kind `delete` or `move`. It is not silently absent. Pinned in Task 12.

```python
# tests/test_frontmatter_keys.py
import pathlib, re, yaml
ROOT = pathlib.Path(__file__).parent.parent
SKILL_KEYS = {"name","description","allowed-tools","user-invocable","disable-model-invocation",
              "model","effort","context","metadata","argument-hint"}
AGENT_KEYS = {"name","description","tools","disallowedTools","model","omitClaudeMd","color","effort"}

def _fm(path):
    text = path.read_text(encoding="utf-8")
    m = re.match(r"---\n(.*?)\n---\n", text, re.S)
    return yaml.safe_load(m.group(1)) if m else {}

def check_skill(path):
    fm = _fm(path); out = [f"unknown skill key {k}" for k in fm if k not in SKILL_KEYS]
    if "Use when" not in str(fm.get("description","")): out.append("description lacks 'Use when'")
    if len(path.read_text(encoding="utf-8").splitlines()) > 500: out.append("SKILL.md > 500 lines")
    return out

def check_agent(path):
    fm = _fm(path); out = [f"unknown agent key {k}" for k in fm if k not in AGENT_KEYS]
    if fm.get("omitClaudeMd") is not True: out.append("omitClaudeMd not true")
    return out

def test_bad_fixture_is_caught():
    assert check_skill(ROOT/"tests/fixtures/frontmatter/bad-skill/SKILL.md")

def test_all_skills_clean():
    bad = {str(p): check_skill(p) for p in (ROOT/"src/skills").glob("*/SKILL.md")}
    assert not {k:v for k,v in bad.items() if v}

def test_all_agents_clean_and_no_phantoms():
    agents = list((ROOT/"src/agents").glob("*.md"))
    assert not (ROOT/"src/agents/memory").exists(), "agents/memory creates phantom agents"
    bad = {str(p): check_agent(p) for p in agents}
    assert not {k:v for k,v in bad.items() if v}
```
