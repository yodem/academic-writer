Academic Writer: the full guide

A writing assistant for humanities researchers. It helps you write a scholarly article in your own voice, using only the sources you choose, and hands you a Word file.

1. What it does

Academic Writer is a plugin (an add-on) for Claude Code, Anthropic's AI assistant that runs in a text window on your computer. You talk with Claude in plain language, and the plugin guides the conversation from a vague topic to a finished, footnoted article.

Your voice

It can study your past articles and learn how you write: sentence length, the phrases you favour, how you open and close an argument.

Real citations only

Every footnote is checked against the sources you picked. A separate checker rejects any paragraph whose citation it cannot confirm.

You stay in charge

You choose the topic, the sources, the thesis and the outline. Nothing is drafted until you approve the plan.

Word in, Word out

You get a .docx file. Comment on it in Word, and the plugin folds your comments back into the text.

It works in Hebrew and in English, including right-to-left layout and Hebrew footnotes. For example, a Hebrew paragraph in the finished file looks like this:

הטענה המרכזית של המאמר היא שהפולמוס לא נסב על שאלת הסמכות בלבד, אלא על הגדרת הקהילה עצמה.1

2. Before you start

You need three things. Setup (step 4) checks each of them for you and explains anything that is missing.

Helpful, but optional:

  • 5 to 10 of your published articles (PDF or Word), so the plugin can learn your writing style.
  • Your source texts as PDFs or Word files. The optional Trove library (an online bookshelf for your sources) lets the plugin search them page by page.
  • Python 3, a free program that reads and writes Word and PDF files. Macs and most Linux computers already have it. Setup checks, and asks before installing the small helper packages it needs.

3. Install

Installing happens once. Open Claude Code (see "How to open a terminal" below if you have not used one), then type these two lines one at a time, pressing Enter after each:

/plugin marketplace add yodem/academic-writer
/plugin install academic-writer@yodem

The first line tells Claude Code where to find the plugin (a marketplace is simply a list of plugins). The second installs it. Close Claude Code and open it again so the new commands appear.

If you prefer the regular terminal window instead of Claude Code's chat, the same two steps are:

claude plugin marketplace add yodem/academic-writer
claude plugin install academic-writer@yodem
How to open a terminal and start Claude Code

A terminal is a window where you type commands instead of clicking.

  • Mac: press Cmd+Space, type Terminal, press Enter.
  • Windows: open the Start menu, type Terminal (or PowerShell), press Enter.
  • Linux: press Ctrl+Alt+T on most systems.

Then go to the folder where you keep your research. Type cd (with a space), drag the folder from Finder or File Explorer into the window, and press Enter. Now type claude and press Enter. Everything the plugin creates for this project stays inside that folder.

4. First run

In Claude Code, inside your research folder, type:

/academic-writer:setup

Setup is a short conversation, one question at a time, about 10 minutes. It:

  1. asks your field of study and the citation style you use;
  2. walks you through getting a free Gemini key, click by click, and tests that it works;
  3. checks the small helper tools the plugin needs and asks your permission before installing anything;
  4. writes one short sample paragraph so you can see it working.
Getting a Gemini key yourself (if you want to do it before setup)
  1. Open aistudio.google.com/apikey in your web browser.
  2. Sign in with any Google account.
  3. Click Create API key. Copy the key; it starts with AIza.
  4. Keep it private, like a password. Setup tells you exactly where to paste it.

After setup, if you want the plugin to learn your personal style, put 5 to 10 of your published articles in the past-articles folder that setup created, then run:

/academic-writer:init

init reads your articles, shows you what it learned about your style so you can correct it, and helps you connect your source library. It is safe to run setup or init again later; they update your profile and never erase it.

5. Your first article

Type /academic-writer:write. The first part is a conversation; the second part the plugin does on its own while you wait.

  1. Topic and language. Say what you want to write about, as roughly as you like, and in which language. Claude asks follow-up questions.
  2. Choose your sources. You see the sources you have made available and pick the ones for this article.
  3. Deep reading. The plugin reads the chosen sources and maps the evidence they contain: arguments, quotations, page numbers, and gaps.
  4. Thesis. You get two or three possible theses based on that evidence. Pick one, adjust one, or write your own.
  5. Outline. Together you shape the sections and what each one argues. Nothing is written until you say the outline is ready.
  6. Drafting. The plugin writes the article paragraph by paragraph from the approved outline, in your style.
  7. Citation check. A separate checker compares every footnote with your sources. Paragraphs that fail are rewritten; if one still fails, it is named for you to look at.
  8. Word file. You receive a .docx with real Word footnotes and a bibliography. Claude tells you where it saved it.
  9. Your comments. Open it in Word. Add comments or tracked changes anywhere you want something changed. Save and close it.
  10. Revise. Run /academic-writer:revise. It reads your comments, groups them, asks you to confirm each group, updates the text and makes a new Word file. Repeat 9 and 10 as often as you like.

Before you submit: run /academic-writer:proofread for a final typo and language pass (you get a marked-up copy and a short report), and /academic-writer:review for a scorecard of the article's structure, argument and citations.

Type any of these in Claude Code. This list is generated from the plugin itself, so it always matches the version you have installed.

/academic-writer:editRevise an article you already drafted: several passages at once, tone, structure, argument order or evidence.

You can also just describe what you want in your own words ("proofread my article", "how does this plugin work?"); Claude picks the right command for most requests. Setup, init and voice only run when you type them, because they change your settings.

7. Where your files live

There are two places. Neither is uploaded anywhere by the plugin except as described under Privacy.

In your research folder (one per project)

Folder or fileWhat it holds
past-articles/Your published articles, for learning your style.
.academic-helper/The project's working files: your profile (profile.md), the list of sources and their citation details, the outline, the drafts of each paragraph, and a log of each run.
ocr-output/Text extracted from scanned pages by /academic-writer:ocr.
Your .docx filesThe finished articles. Claude tells you the file name each time.

Folders whose names start with a dot, like .academic-helper, are hidden by default. To see them: on a Mac, press Cmd+Shift+. in Finder; on Windows, open File Explorer, choose View, then Show, then Hidden items.

In the plugin's own data folder (shared by all your projects)

Your voice data (the passages you chose as examples of your style, the writing habits the plugin learned, your preferred terms, and the before-and-after pairs from your own corrections) lives in one place so every project benefits. It is inside your home folder under .claude/plugins/data/, in a folder whose name starts with academic-writer. The same folder keeps a small log of plugin mistakes you flagged during /academic-writer:revise, so they can be fixed.

This folder survives plugin updates. It is removed if you uninstall the plugin, unless you ask to keep it (see section 10).

8. Privacy

  • Anthropic (Claude). Your conversation with Claude, and the text Claude reads to help you (your drafts, the passages of sources it checks), are sent to Anthropic, as with any use of Claude Code.
  • Google (Gemini). If you set up a Gemini key, the paragraphs being drafted, edited, proofread or summarised, the source passages they rely on, and any scanned pages you ask it to read are sent to Google's Gemini service. On Google's free tier, Google may use what you send to improve its products; check Google's current terms, and consider a paid key for unpublished work you consider sensitive.
  • Trove (optional). Only the sources you choose to upload to your Trove library are stored there.
  • Your keys. When you save your Gemini key through the plugin's settings, Claude Code stores it in your computer's secure keychain (or a protected credentials file), never in a plain text file in your project. The plugin never prints it or writes it into your research folder.
  • Nothing else. The plugin writes only inside your research folder and its own data folder. It does not send your files anywhere else.

9. Troubleshooting

First, always: type /academic-writer:health. It checks your profile, key, tools and sources and tells you, in plain words, what to fix.

The /academic-writer: commands do not appear

Close Claude Code completely and open it again; new plugins load at start-up. If they still do not appear, type /plugin and check that academic-writer is listed and enabled. If it is missing, repeat the two install lines in section 3.

"No Gemini key" or "API key not valid"

Run /academic-writer:setup again and choose to set up Gemini. After saving a key, start a new Claude Code session: the key is picked up when a session starts. If Google says the key is invalid, create a fresh one at aistudio.google.com/apikey and copy it again, with no spaces before or after.

"No profile found"

The plugin keeps one profile per research folder. Check that you started Claude Code inside your research folder (section 3, "How to open a terminal"). If this is a new folder, run /academic-writer:setup there.

"Missing Python package" or the Word file is not created

Run /academic-writer:setup; it checks the helper packages and offers to install them for you. If you prefer to do it yourself, paste this into a terminal:

python3 -m pip install python-docx lxml pdfplumber pymupdf jsonschema

If the computer says python3 was not found, install Python 3 from python.org/downloads (on Windows, tick "Add Python to PATH" during installation), then try again.

Hebrew text looks reversed or punctuation is in the wrong place

In Claude Code's window, mixed Hebrew and English can look jumbled; that is only the display. The Word file is laid out right to left. If the Word file itself looks wrong, make sure your article language in the profile is Hebrew (run /academic-writer:setup to check) and tell Claude what you see.

Something behaves strangely after an update

Update both the plugin list and the plugin, then restart Claude Code (section 10). If that does not help, run /academic-writer:health and share its report when asking for help.

Still stuck? Report the problem at github.com/yodem/academic-writer/issues and include the output of /academic-writer:health (it contains no keys).

10. Updating and uninstalling

Updating

Type these in a terminal (or with /plugin in Claude Code), then restart Claude Code:

claude plugin marketplace update yodem
claude plugin update academic-writer@yodem

Updating keeps your profile, drafts and voice data.

Uninstalling

Important: uninstalling normally deletes the plugin's data folder, which holds your voice data (section 7). To keep it, add --keep-data:

claude plugin uninstall academic-writer@yodem --keep-data

Your research folders, drafts and Word files are never touched by uninstalling.
