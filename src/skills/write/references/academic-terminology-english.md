> from:

>   (AI-writing tells, formulaic hedging, inflated language, capped per-article).

## A. Hedging / Stance Verbs

Use these to calibrate certainty without resorting to the inflated absolutes flagged in
anti-ai-patterns-english.md ("undoubtedly," "clearly," "obviously").

| Term | Register / use |
|---|---|
| suggests | tentative claim from evidence |
| indicates | moderate-confidence claim |
| appears to | visible pattern, unconfirmed cause |
| may be understood as | offering an interpretive frame |
| can be read as | alternative-reading hedge |
| seems to | mild hedge, observational |
| points to | evidence-based inference |
| implies | logical entailment, softened |
| tends to | pattern across cases, not universal |
| is likely to | probabilistic claim |
| arguably | signals a defensible but contestable claim |
| plausibly | reasonable but unproven |
| on this reading | scoping a claim to one interpretation |
| in this light | scoping a claim to a preceding frame |
| it would seem that | formal hedge, softens assertion |
| one might argue that | introduces a position without full commitment |
| this raises the possibility that | opens speculative ground carefully |
| warrants further consideration | flags an open question without overclaiming |
| is not without difficulty | signals awareness of a weakness in one's own claim |
| falls short of establishing | precise limitation of what evidence shows |

## B. Argumentation Vocabulary

Connective and structural vocabulary for building and qualifying an argument.

| Term | Function |
|---|---|
| this raises the question of | pivots from observation to inquiry |
| it follows that | signals valid inference |
| conversely | marks a contrasting case |
| by the same logic | extends an argument by analogy |
| by contrast | direct opposition between two claims |
| nevertheless | concedes a point while maintaining the thesis |
| nonetheless | same function, more formal register |
| notwithstanding | concession, formal register |
| that said | informal-adjacent concession — use sparingly in body prose |
| granted that | explicit concession before rebuttal |
| even so | concession pivot |
| this is not to say that | forestalls a misreading of the preceding claim |
| it does not follow that | blocks an invalid inference |
| a further complication is | signals added nuance |
| this complicates the picture | signals added nuance, less formal |
| taken together, these observations suggest | synthesizing multiple points |
| on closer examination | signals a shift from surface to deeper reading |
| what emerges from this comparison is | synthesis after juxtaposition |
| the significance of this lies in | pivots from description to interpretation |
| this bears directly on | connects a point back to the thesis |
| at stake here is | frames the interpretive stakes |
| the distinction is not merely terminological | defends the importance of a definitional point |
| this is best understood in relation to | frames a claim relative to context |
| a more productive framing is | proposes an alternative approach |
| the tension between X and Y is instructive | uses a contradiction analytically |

## C. Citation-Introduction Verbs

Vary the verb that introduces a scholar's position — avoid defaulting to "says" or "writes"
throughout. Match the verb to what the source actually does.

| Term | What it signals |
|---|---|
| argues | asserts a position with support |
| contends | argues, often against an opposing view |
| demonstrates | shows conclusively via evidence |
| notes | makes a supporting or secondary observation |
| observes | records a finding, often descriptive |
| maintains | holds a position, possibly against challenge |
| claims | asserts, neutral to skeptical framing |
| suggests | tentative scholarly proposal |
| proposes | introduces a new framework or reading |
| posits | introduces a theoretical premise |
| establishes | secures a point with strong evidence |
| shows | demonstrates, plain register |
| illustrates | supports a point with example |
| emphasizes | foregrounds one element of an argument |
| stresses | same, slightly stronger |
| cautions | flags a limitation or risk |
| challenges | disputes a prior position |
| critiques | evaluates and finds fault |
| qualifies | narrows or conditions an earlier claim |
| distinguishes between | draws an analytical distinction |
| traces | follows a development historically |
| situates | places a text/idea in context |
| reads X as | offers an interpretive framing |
| characterizes | describes the nature of something |
| concludes | ends an argument with a summary claim |

## D. Section-Transition Phrases

Use to move between sections/paragraphs without resorting to the numbered "firstly/secondly"
scaffolding or the topic-tag opener ("Regarding X...") both flagged as AI tells.

| Phrase | Use |
|---|---|
| building on the foregoing | resumes an argument already established |
| in what follows | signals the shape of the coming discussion |
| turning now to | pivots to a new but related topic |
| with this in view | connects a preceding point to what comes next |
| against this background | frames new material relative to prior context |
| having established X, we can now consider Y | explicit but non-formulaic bridge |
| this brings us to | natural transition to next point |
| the foregoing discussion bears on | links backward before moving forward |
| it remains to consider | signals an unaddressed but necessary point |
| a related question concerns | pivots to an adjacent issue |
| this dovetails with | connects two lines of argument |
| returning to X | resumes an earlier thread after a digression |
| set against this backdrop | situates new material in relation to prior discussion |
| the discussion so far has shown | summarizes before pivoting |
| what remains is to examine | signals the final piece of an argument |
