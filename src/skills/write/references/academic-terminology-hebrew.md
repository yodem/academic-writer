# מונחי רישום אקדמי — מילון חיובי בעברית (Hebrew Positive Vocabulary Reference)

> **זהו מקור חיובי — מונחים שיש לאמץ.** זהו קובץ אחות, ומובחן במפורש, מ:
> - [`anti-ai-patterns-hebrew.md`](./anti-ai-patterns-hebrew.md) — תבניות/ביטויים שיש **להימנע**
>   מהם (סימני כתיבת AI, פתיחות שבלוניות, שפה מנופחת — עם תקרות שימוש למאמר).
> - [`../../../words-hebrew.md`](../../../words-hebrew.md) — רשימת **אמצעי הקישור** שכל פסקה
>   נדרשת לשאוב ממנה (נבדל מבלוק `bannedTerms` הנפרד, הנטען מ-`profile.md` ומכיל מונחים
>   שאסור שיופיעו כלל).
>
> בעוד קובצי anti-ai והמונחים האסורים מציינים למחבר מה למחוק, קובץ זה מציין למחבר לאן לפנות
> במקום זאת — רישום אקדמי הולם ואותנטי למדעי הרוח בעברית. הקובץ נטען על ידי
> `/academic-writer:review` (ממד 6, רישום המונחים) עבור מאמרים ש-`targetLanguage` שלהם הוא עברית. יש להיוועץ בו
> לפני ובמהלך הכתיבה, לא כמעבר חיפוש-והחלפה בדיעבד.
>
> **הערה:** חלק מהמונחים כאן (למשל `יתרה מזאת`, `זאת ועוד`, `בהקשר זה`) מופיעים גם ב-
> `anti-ai-patterns-hebrew.md` עם **תקרת שימוש** למאמר — הם תקינים ורצויים ברישום, אך שימוש
> חוזר יוצר תבנית מכנית. השתמשו בהם במידה, לא כברירת מחדל.

## ג. פעלי הצגת ציטוט ומקור (Citation-Introduction Verbs)

מגוונים את פועל ההצגה של עמדת חוקר — יש להימנע מחזרה על "כותב/אומר" בלבד לאורך כל המאמר.

| מונח | מה הוא מסמן |
|---|---|
| טוען | הצגת עמדה נתמכת |
| קובע | קביעה מבוססת, ודאות גבוהה יחסית |
| מציין | תצפית תומכת או משנית |
| מדגיש | הבלטת יסוד מסוים בטיעון |
| מבהיר | הבהרת נקודה עמומה |
| מראה | הדגמה מבוססת ראיות |
| מוכיח | הוכחה חד־משמעית |
| מציע | הצעת מסגרת פרשנית או תזה חדשה |
| מבחין בין | הבחנה אנליטית בין שני מושגים |
| מתאר | תיאור, רישום ניטרלי |
| מנתח | ניתוח שיטתי |
| בוחן | בדיקה שיטתית של שאלה |
| דן ב־ | עיסוק מורחב בנושא |
| עומד על | הבלטת יסוד חשוב במיוחד |
| חולק על | הבעת אי-הסכמה עם עמדה קודמת |
| מסתייג מ־ | הבעת הסתייגות מבוססת |
| מבקר | ביקורת שיטתית |
| מתייחס ל־ | התייחסות כללית לסוגיה |
| מגדיר | קביעת מובן מונח |
| ממקם את X בהקשר של | הצבת רעיון בהקשרו ההיסטורי/תיאורטי |
| מסכם | חתימת טיעון |
| מסייג את קביעתו | צמצום טענה קודמת של אותו חוקר |

## ד. ביטויי מעבר בין פרקים ופסקאות (Section-Transition Phrases)

יש להימנע מהמבנה הממוספר השבלוני ("ראשית... שנית... שלישית") וגם מפתיחת פסקה בתיוג נושא
("מבחינת X...") — שני אלה מסומנים כסימני AI ב-anti-ai-patterns-hebrew.md.

| ביטוי | שימוש |
|---|---|
| בהמשך לאמור | חידוש טיעון שכבר הוצג |
| בפרק הבא נבחן | הכוונת הקורא לדיון הבא, בלי לחזור על נוסחת פתיחה זהה בכל פרק |
| בשלב זה ראוי לפנות אל | מעבר טבעי לנושא סמוך |
| על רקע זה | מיקום חומר חדש ביחס להקשר קודם |
| לאחר שהוצגה X, ניתן כעת לבחון את Y | גשר מפורש אך לא שבלוני |
| הדברים שנאמרו עד כה מלמדים על | סיכום ביניים לפני מעבר |
| נותר לבחון | סימון נקודה שטרם נדונה אך נדרשת |
| שאלה קרובה נוגעת ל־ | מעבר לסוגיה סמוכה |
| חוזרים כעת אל | חידוש דיון קודם לאחר סטייה |
| בהינתן הרקע שהוצג | מיקום חומר חדש ביחס לרקע |
| הדיון עד כאן הראה כי | סיכום לפני פנייה חדשה |
| נותר לבדוק | סימון החלק האחרון בטיעון |
